# Полное воспроизведение V5

Здесь сохранены полный исходный код на момент запуска, исходные данные, все три каталога цепочки восстановления, команды и логи, проверки и результаты. Краткое описание гипотезы, методов и результатов находится [уровнем выше](../README.md).

## Состав

- `runtime-source.zip`: все отслеживаемые файлы FEDOT.Swarm на коммите `528dcad4`, включая три Python-пакета, движок исполнения, runner V5, восстановление, тесты, `pyproject.toml` и `uv.lock`. Файлы скопированы побайтно из рабочего дерева. Все хеши frozen-протокола совпадают. Экспериментальная процедура относится к `b0bcaea1`; коммит `528dcad4` добавил обработчик восстановления.
- `evidence.zip`: исходный запуск, recovery1 и recovery2, все API-запросы и ответы, исторические незавершённые попытки, оценки, итоговые результаты, снимки датасета, планы предыдущих версий для исключения вопросов, команды, журналы и полный локальный аудит от 5 ноября.
- `manifest.json`: хеши архивов, число файлов, версии Python и библиотек исходного окружения.
- `replay.py`: полное выполнение исходного runner на сохранённых ответах. Не вызывает модель.
- `build_archive.py`: код сборки архивов из исходного рабочего пространства. Для использования архива повторная сборка не нужна.

Оба ZIP содержат `SHA256.json` со всеми внутренними файлами. Исходные результаты не перезаписаны. Абсолютные пути в исторических логах оставлены как свидетельство фактических команд; для нового запуска их нужно заменить своими. Файлы `.env`, ключи и виртуальное окружение не включены.

## Подготовка окружения

Нужны Python 3.11+ и uv. Из каталога `full-reproduction` распакуйте архивы:

```sh
python -m zipfile -e runtime-source.zip .
python -m zipfile -e evidence.zip evidence
cd runtime-source
uv sync --frozen --all-packages --group paperbench
```

Следующие команды выполняются из `runtime-source`. Для Windows, macOS и Linux используйте свои абсолютные пути вместо `/absolute/...`. `uv.lock` фиксирует зависимости; каталог `.venv` создаётся заново.

## Полное воспроизведение без оплаты

```sh
uv run --frozen python ../replay.py --source . --evidence ../evidence --output ../replay-output
```

Скрипт проверяет исходные хеши, точное совпадение запросов, однократное использование всех 3312 ответов, 1400 оценок и результаты трёх повторов. Выходной каталог должен отсутствовать. Быстрый автономный пересчёт без внешних библиотек также доступен: `python ../../verify.py` из каталога `runtime-source`.

## Новый платный запуск исходного V5

Укажите собственный `OPENROUTER_API_KEY` в окружении или в отдельном `.env`, который не добавляется в Git. Полный запуск делает реальные API-вызовы; свежие ответы и результаты могут отличаться от исторических.

```sh
uv run --frozen python -m benchmarks.workflow_search.record --output /absolute/new-runs/commands/v5-fresh --keep-awake -- uv run --frozen python -m benchmarks.workflow_search.confirmed --plan /absolute/evidence/workflow-runs/main-v5-confirmed-plan.json --name v5-fresh --env-file /absolute/private/.env
```

Сам runner создаёт каталог результата рядом с файлом плана. Для удобства скопируйте план в `new-runs` и передайте путь к этой копии. Имя нового запуска и каталог команд должны быть новыми. Эти команды воспроизводят первоначальную процедуру; фактическое продолжение 6 октября использовало `recover_confirmed.py`, а его вызов сохранён в `evidence/workflow-runs/commands/main-v5-confirmed-recovery2/run.json`.

Первоначальная процедура сохраняет ошибки и не делает повтор HTTP-отказов. Автоматические транспортные повторы ограничены; для восстановления после остановки требуется сначала проверить сохранённые попытки. Справка: `uv run python -m benchmarks.workflow_search.recover_confirmed --help` и `docs/development/workflow-search/V5_RECOVERY.md`.

## Учёт расходов

Все три каталога сохранены для истории. Для итоговых расходов используйте только `main-v5-confirmed-recovery2`: его `calls` и `interrupted_attempts/calls` уже включают унаследованные попытки. Складывать расходы трёх каталогов нельзя. Итог: $1.90427392 известных расходов и 13 попыток с неизвестной стоимостью. Расходы на выбор и тест учитываются раздельно.
